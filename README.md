Este programa foi criado em novembro/dezembro de 2025.
 
🌱 **Eco Quiz Estruturado**
 
Um mini jogo educativo com foco em conscientização ambiental, onde o jogador responde perguntas e aprende enquanto joga.
 
📌 **Sobre o Projeto**
 
O Eco Quiz Estruturado é um projeto desenvolvido em HTML, CSS e JavaScript, com o objetivo de ensinar conceitos ambientais de forma leve e divertida.  
O jogo apresenta perguntas e opções de resposta para engajar o usuário. 
🧩 **Funcionalidades**
 
✔️ Interface simples e amigável
 
✔️ Perguntas sobre meio ambiente
 
✔️ Efeitos sonoros e visuais
 
✔️ Contagem de acertos
 
✔️ Layout responsivo
 
✔️ Código organizado e estruturado
 
 
🛠️ **Tecnologias Utilizadas**
 
HTML5
 
CSS3
 
JavaScript
 
Git & GitHub
 
 
🎮 **Como jogar**
 
Abra o arquivo index.html no navegador
 
Responda às perguntas
 
Veja sua pontuação final
 
Reinicie e tente novamente!
